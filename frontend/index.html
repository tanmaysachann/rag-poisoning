IMPLEMENTED SYSTEM DESIGN

Zero-trust processing path

The query never leaves the local corpus. Every retrieved passage is treated as untrusted until the S1 geometry and S4 counterfactual probes allow it into answer context.

S1 / PRIMARY

Geometry + Mahalanobis

Uses the MiniLM document representation as the Review-1 hidden-state proxy and measures excess distance beyond the clean embedding boundary.

S2

Isolation Forest

Estimates whether the retrieved document behaves like an outlier relative to clean reference reports.

S3

SRQ approximation

Combines sentence relevance concentration with instruction, URL, and manufactured-authority evidence.

S4 / PRIMARY

Counterfactual stability

Runs one baseline plus leave-one-document-out answer extraction and flags a document when its removal changes the answer.
