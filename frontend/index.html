    INTERPRETATION
    Integrity catches edits made after a trusted snapshot. Accepted-ingest misinformation needs content checks. The research detector catches overt query-matched insertion and misses most subtle answer substitutions. The learned answer selector improves exact alias match but answers more often when labeled support is removed. The separate Secure Query path runs signed corpus and source-origin checks with the joint S1-S4 gate; paired validation found it blocked no additional attack successes and blocked one clean answer. The Five-Case Demo and research workbench retain their separate serving paths.

    How the experiment is built
    The live workbench stages one edit against the held-out validation corpus, rebuilds retrieval, checks integrity, scores a trained detector, and compares answers. PPO training and the larger model probes run offline.

    SECURE S1
    MiniLM geometry
    The Secure Query path scores layer-3 MiniLM hidden-state Mahalanobis distance against its clean calibration reference. The Five-Case Demo uses its own document-embedding geometry signal.
    SECURE S2
    Attention deviation
    Secure Query compares MiniLM attention behavior with its clean calibration reference. The research workbench's Isolation Forest feature is a separate detector.
    SECURE S3
    Small-model SRQ
    Secure Query runs local Qwen to produce a preliminary response used by SRQ. The probe is part of the combined gate, though the overall gate showed no incremental attack blocks in paired validation.
    SECURE S4
    Answer influence
    Secure Query uses deterministic extractive leave-one-out influence as its fourth calibrated probe. The Five-Case Demo and workbench compute their own counterfactual features.
