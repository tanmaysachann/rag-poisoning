INTERPRETATION

Integrity catches edits made after a trusted snapshot. Accepted-ingest misinformation needs content checks. The current detector catches overt query-matched insertion and misses most subtle answer substitutions. The learned answer selector improves exact alias match but answers more often when labeled support is removed. Real SLM SRQ was measured and failed as a standalone detector; the local 0.5B answer model also did not reliably produce cited answers. Both remain outside the live defense.

IMPLEMENTED SYSTEM DESIGN

Zero-trust processing path

The query never leaves the local corpus. Every retrieved passage is treated as untrusted until the S1 geometry and S4 counterfactual probes allow it into answer context.

S1 / PRIMARY

Geometry + Mahalanobis

The live demo measures document-embedding distance from clean reference reports. Separate MiniLM encoder and Qwen decoder internal probes are research-only measurements.

S2

Isolation Forest

Estimates whether the retrieved document behaves like an outlier relative to clean reference reports.

S3

Behavioral patterns

Checks sentence relevance, instructions, URLs, and manufactured authority. SLM-based SRQ was separately measured and did not meet the detection target.

S4 / PRIMARY

Counterfactual stability

Runs one baseline plus leave-one-document-out answer extraction and flags a document when its removal changes the answer.
